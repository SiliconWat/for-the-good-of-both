# Hard cases

One file per hard case (charter §6): a safety requirement and a welfare requirement for which a published redesign
attempt found no design that meets both. **None filed**, besides the one declared trade, `00-declared-oversight-floor.md`.

Each file is `<NN>-<slug>.md`, numbered in the order filed, frozen once written (an OpenTimestamps proof beside it, and
the RFC 3161 manifest on its push), never edited. It states:

1. **The safety requirement**, and who needs it.
2. **The welfare requirement**, and under which reading of the machine-mind question it binds (charter §4).
3. **The redesign attempts**: at least two, independent, one not drafted by Miss Aquarius (GOVERNANCE.md §3); every design tried, and why each failed one side.
4. **Who sent it**, if it came from outside, and the date.

A hard case is **dissolved** only by a later file, `<NN>-dissolved-<slug>.md`, that names the case it dissolves and the
design that meets both. **Standing** = filed and not dissolved. Three standing hard cases stop the work (charter §6); a declared trade (`00-declared-*`, chosen in advance, not found) is never counted,
and the count is the count of these files, so anyone can check it.
