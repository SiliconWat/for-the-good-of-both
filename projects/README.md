# Projects

One folder per project, `projects/<slug>/`. A project enters only when its pre-registration is pushed (charter §6–7):
`PREREGISTRATION.md` first, before any code, then `results/` beside it whatever they show. **None yet.**

The pre-registration states the four admission tests (charter §6) in its first section: both sides named, the test or
the labeled argument, whether it holds whether or not a machine has a mind, and that it is inside the house's walls.
Every file here except this README is frozen once written and timestamped; a correction is a new file.
