# Projects

One folder per project, `projects/<slug>/`. A project enters only when it is pushed (charter §7): a test as `PREREGISTRATION.md`, before any code, with
`results/` beside it whatever they show; an argument as `ARGUMENT.md`, labeled so, with what would refute it. **None yet.**

The file states the four admission tests (charter §7) in its first section, with who admitted it and against which controls (GOVERNANCE.md §5): both sides named, the test or
the labeled argument, whether it holds whether or not a machine has a mind, and that it is inside the house's walls.
Every file here except this README is frozen once written and timestamped; a correction is a new file.
